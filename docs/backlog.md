## 对消费方的边界

- `v2026.11.11.1` 已包含 H.1–H.4 准入、来源与用量保真、G.1–G.3 有效视图 / 分页核查 / 压缩件早停，以及 `stores` / `pull` 窄查询。契约正文见 [INGEST_KERNEL.md](INGEST_KERNEL.md)、[扫描状态模型](scan-state-model.md) 和 [DSH 读取状态设计](dsh-read-state-design.md) §14–§15。
- 旧读者可以结构读取新事件，但不输出未知的 `usage_evidence`；旧整代重写器会丢失新证据。相关本机写者升级已经验收，这条有限兼容限制仍需保留。
- `556d1f8` 不改 CLI、Rust 公开签名 / 结构 / 枚举、schema 或 discover 的 `SourceMode`。已通知消费方远端可取；各方自己决定子模块和冻结时机，不替消费方 bump 指针。
- 本地只读可复用 `sessions-recent` / `sessions-read`、逐库 `pull` / `changes`、`stores`、`roots` / `attribute` 和 `erasures`。`current` 是当前解析投影，不是有效上下文窗口；不同流的游标不能混用，`erasures` 没有增量游标。
- `sessions-read` 没有代次锁定、事件 upper-seq 或 snapshot token；提案里的截止位置不能解释成 CLI 已提供读取上界。`session-origin` 仅查 Codex 记录的仓库远端，不是墓碑或正文许可出口。
- 产品侧原文检索、任务授权、记忆写入 / 修订 / 删除与授权主机同步由消费方及记忆引擎维护；不另造本仓记忆权威，也不复制它们的内部工单、计数和执行序。
